# Fusionify Coffee Customer App

Flutter customer application for Fusionify Coffee.

## Stack

- Flutter 3.47
- Dart
- Riverpod
- GoRouter
- Dio
- Android API 28+ with compile/target API 36
- iOS target generated by the shared Flutter project and subject to final platform review

## Current Scope

Milestone 0.1 currently includes:
- App shell and bottom navigation
- Solid-color Fusionify design tokens
- Development preview outlet
- Menu/category discovery
- Product modifier selection
- Size, temperature, sugar, ice, milk, and add-ons
- Cart with distinct configuration identity
- Quantity and subtotal behavior

Checkout, real payment, authentication, rewards, delivery, and production catalog data are not implemented yet.

## Development

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

The preview catalog is intentionally marked as development data. Do not present it as production data.

## Android

Current generated application ID is `id.fusionify.coffee`, but it remains provisional until the project explicitly locks the production package ID.

Release signing with the real upload keystore is not configured in Git and must follow `../../docs/android/SIGNING.md`.
