# Customer Demo Screenshots

These screenshots are rendered from the real Flutter customer widgets at a 390 x 844 logical-pixel viewport with the bundled development catalog fixture.

- `fusionify-coffee-home-demo.png`: Home, outlet, campaign, and fulfillment preview.
- `fusionify-coffee-menu-demo.png`: Menu categories and product grid preview.

They are representative UI captures, not edited marketing mockups. Device chrome is omitted because the capture runs through Flutter's deterministic golden renderer rather than an Android emulator.
