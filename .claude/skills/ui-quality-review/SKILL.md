# UI Quality Review

Review the changed UI for:
- No gradients
- No copied competitor assets or layout cloning
- No arbitrary colors, spacing, radius, typography, or elevation
- No excessive card nesting
- No unnecessary shadows
- No emoji used as production iconography
- No generic AI marketing copy
- Clear primary action
- Appropriate loading, empty, error, and disabled states
- Accessible contrast and semantics
- Responsive behavior
- Product photography used purposefully
- Pickup/delivery/order/payment state clearly communicated

Report concrete violations with file/component references.
